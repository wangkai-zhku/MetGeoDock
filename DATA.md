# Data index

Every file used by the manuscript, grouped by how it is produced. Paths are relative
to the repository root.

Legend: **raw** = downloaded or exported, not regenerated by this repo;
**derived** = produced by a script in `scripts/`; **analysis** = derived from other
derived files.

---

## 1. Raw inputs (`processed/`)

| Directory | Contents | Provenance |
|---|---|---|
| `processed/chembl/curated/` | `all_targets_molecules.csv` — ChEMBL 37 activity records with `pactivity`, `metal`, `target_name`, `pdb`, `canonical_smiles` | exported from ChEMBL; not regenerated here |
| `processed/chembl/` | per-target curation intermediates | derived from the export above |
| `processed/crystal/` | PDB inventory tables (metal counts, resolution, ligand presence) | derived by scanning PDB files |
| `processed/maps/`, `processed/ff/` | GPDOCK histogram maps and force-field parameter tables | shipped parameters, treated as raw |
| `processed/gpdock_orig/` | original GPDOCK outputs used for cross-checks | raw |
| `processed/metallodock_541/` | reconstruction of the MetalloDock benchmark set | derived |
| `processed/splits/` | train/test splits (time-split, PDB-cluster split) | derived |
| `processed/bindingdb/`, `processed/qm/` | BindingDB dump, cluster QM inputs | mixed raw/derived |

## 2. Docking outputs (`docking/`, `results/*_scores/`)

| Path | Contents |
|---|---|
| `docking/results/` | HDAC 7-subtype small-library screen (200 molecules/target) — lives under `~/cursor-task/HDAC/docking/results/` |
| `docking/poses_sd/` | best pose PDB per ligand (HDAC set) — under `~/cursor-task/HDAC/docking/poses_sd/` |
| `docking/biglib/` | large decoy libraries per HDAC subtype (3,853–5,996 decoys) |
| `results/biglib_scores/` | large-library screen results (HDAC1, HDAC2 complete) |
| `results/diverse_scores/` | chemically diverse decoy library results |
| `results/hdac_vs/` | HDAC virtual-screening benchmark metrics and YAML protocol |

## 3. Multi-metal benchmark (`results/crossfamily*/`)

| File | Contents |
|---|---|
| `results/crossfamily/{metal}.csv` | per-metal benchmark: ligand, label, E score, target |
| `results/crossfamily_fe3.csv` | heme-iron (Fe(III)) benchmark, iron extracted from HEM |
| `results/metal_site_landscape.csv` | per-target AUROC / EF1% of the geometric term |
| `results/pocket_descriptors.csv` | coordination number, donor composition, burial per receptor |

Regenerated by `scripts/analysis/build_crossfamily_set.py` and
`scripts/analysis/heme_to_fe3.py`.

## 4. Entropy descriptors (`results/entropy_big/`, `results/h_free*`)

| Path | Contents |
|---|---|
| `results/entropy_big/{metal}_{target}.csv` | per ligand: `E_best`, `h_free`, `n_clusters`, `n_poses`, `label` |
| `results/hfree_big/` | conformational free energy alone (HDAC + cross-family) |
| `results/itpe/` | ITPE three-term entropy decomposition (HDAC actives only) |
| `results/entropy_parts/`, `results/entropy_decoys/` | HDAC actives / property-matched decoys |

Regenerated by `scripts/analysis/entropy_all_targets.py`.

## 7. Regeneration order

```bash
# 1. receptors (requires metgeodock[prep])
python scripts/analysis/entropy_all_targets.py --metal zn --target CA2

# 2. all entropy descriptors (long: ~1 h parallelised by metal/target)
for m in zn ca mg mn fe2 fe3 co cu ni cd; do
  python scripts/analysis/entropy_all_targets.py --metal $m &
done

# 3. metrics
python scripts/analysis/eval_biglib.py      # large-library HDAC benchmark
python scripts/analysis/metric_panel.py     # cross-family metric panel

# 4. figures
python scripts/manuscript/figures/fig1_screening_overview.py
python scripts/manuscript/figures/figS_screening_suite.py

# 5. documents
python scripts/analysis/make_report_docx.py
python scripts/manuscript/build_word_package.py
```

## 8. What is NOT reproducible here

* The ChEMBL 37 export (needs network + licence acceptance).
* `processed/gpdock_orig/` and `processed/metallodock_541/` — external benchmark data.
* Large PDB structures are not vendored; scripts download or expect them under
  `/tmp/xtal_train/` (see `scripts/analysis/build_crossfamily_set.py --pdb-dir`).
